# Front-End Web Development

Proyecto enfocado en la creación de un hub educativo sobre desarrollo web frontend utilizando **HTML5**. Contiene secciones informativas dedicadas a HTML, CSS y JavaScript, complementadas con recursos audiovisuales incrustados mediante reproductores de YouTube.

---

## 🚀 Características

- **Estructura Semántica:** Organización modular del contenido utilizando las etiquetas `<main>` y `<section>`.
- **Incrustación Multimedia:** Uso del elemento `<iframe>` para integrar tutoriales y cursos en video alojados en YouTube.
- **Configuración Segura de Frames:** Implementación de atributos modernos de iframe como `allowfullscreen`, `title` (para accesibilidad) y políticas de referencia (`referrerpolicy`).
